# Jacquard Loom Simulator

An interactive simulator of the Jacquard loom: punch the cards, turn the loom, and watch the head choose every thread. Mechanism in 2D and 3D, lessons and games.

The Jacquard head (Joseph Marie Jacquard, Lyon, 1801–1805) let a chain of punched cards choose which warp threads rise for each throw of the shuttle, so a loom could weave any figure without a draw boy. Babbage took its cards for his Analytical Engine.

The simulator itself arrives with the first release; this commit sets up the repository: the licences, Git LFS for the 3D models, the reference check (`pnpm check:refs`), CI and GitHub Pages.
